# No Pause

A tiny client-side Fabric mod for Minecraft 1.21.11.

## Description

A lightweight mod that allows you to tab out without Minecraft's force pause screen popping up.

## What it does

Minecraft already has a hidden vanilla "pause on lost focus" toggle with F3+P.
This mod just keeps that option disabled for you.

## Features

- Client-side only
- No Fabric API
- No config
- No commands
- No HUD
- No background loop
- Extremely lightweight

## Build

Use Java 21:

```bash
gradle build
```

Output:

```text
build/libs/no-pause-1.0.0.jar
```
